# CloudLab Project

Personal hands-on lab to practice cloud infrastructure and DevOps workflows in a structured way.

## Goal

Build a progressive lab focused on:

- Terraform foundations
- AWS networking
- EC2
- RDS
- Access management
- Observability with Prometheus and Grafana
- CI/CD with CircleCI

## Working model

This lab is designed to be developed incrementally in short weekly sessions.

## Initial project structure

- `terraform/` → Terraform-related root structure or shared configurations
- `modules/` → reusable Terraform modules
- `environments/dev/` → development environment entrypoint
- `.circleci/` → CI/CD pipeline configuration
- `docs/` → notes, roadmap, and documentation
